# VR Worldwide Banking CRM

Next.js interface for the lending assistance desk. Data stays in the browser session. There is no server API.

```bash
pnpm install
pnpm run dev
```

Open http://localhost:3000. Choose a person on the sign-in screen, or use password `welcome`.
